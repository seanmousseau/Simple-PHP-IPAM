# v3.23.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the PDO-based logical restore engine plus backup/restore maintainability cleanups, settle deferred CR debt from v3.21.0 PR #761, and clear two non-backup carryovers (#770 MFA test, #1073 PG VR drift, #1081 mysql client probe).

**Architecture:** Procedural PHP under `Simple-PHP-IPAM/lib/backup.php` and a new `Simple-PHP-IPAM/lib/restore_pdo.php` (per project's procedural-default policy). Restore wizard chooses PDO path for `Logical` backups and shell-out path for `Database` backups (kept as escape hatch per backup_overhaul.md §5d). Tests are PHPUnit unit + Playwright E2E + 3-driver dockerized integration.

**Tech Stack:** PHP 8.2, PDO (sqlite/mysql/pgsql), existing SQL splitter (B-P0-4 from v3.21.0), `BackupClientInterface` (v3.17.0), restore wizard state machine (v3.21.0).
