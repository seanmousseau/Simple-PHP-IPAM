**Goal:** Ship v3.17.0 — combined web-based backup and restore. Admins manage S3-compatible / SFTP / local destinations and schedules from the UI; backups run on a GFS retention curve, are encrypted with AES-256-GCM, and restore through a browser-driven dry-run + confirm flow with full audit.

> **Scope update 2026-04-28:** #756 (settings.php per-toggle save) and #759 (contact-linking docs) have been deferred to v3.18.0 to keep this milestone purely focused on backup/restore. The deleted phases are noted but not renumbered; Phase 16 is intentionally absent.

**Architecture:** Single feature branch `feat/v3.17.0` off `dev`. Phases are mostly independent and ordered to land foundational primitives (schema, encryption, retention, transport clients) before the user-facing flows that compose them. New `Simple-PHP-IPAM/lib/` subdirectory introduced for non-dialect helper classes (`S3Client`, `SftpClient`, `BackupEngine`, `RestoreEngine`). UI work uses the existing `ipam_render($view, $props)` views helper — no new templating. Encryption uses native `openssl_encrypt()`. SFTP requires a new Composer dep (`phpseclib/phpseclib ^3.0`); S3 is hand-rolled (~250–300 lines, AWS Sig V4) per CLAUDE.md "narrow purpose" dep policy. Multi-engine schema parity enforced through `schema.sql` / `schema.mysql.sql` / `schema.pgsql.sql` + `SchemaParityTest`. All binding to binary columns continues to use `ipam_bind_binary()`.

**Tech Stack:** PHP 8.2+, SQLite 3 / MySQL 8.0.29+ / PostgreSQL 14+, vanilla CSS/JS, Heroicons sprite (`assets/icons.svg`), Open Props tokens (already vendored). New runtime dep: `phpseclib/phpseclib ^3.0` (SFTP). No new frontend deps.

### Task 2.3: Implement `backup_encrypt` / `backup_decrypt`

**Files:**
- Modify: `Simple-PHP-IPAM/lib.php`

- [ ] **Step 1: Add the helpers**

```php
const BACKUP_MAGIC   = "IPAMBKP1";   // 8 bytes; version 1
const BACKUP_IV_LEN  = 12;
const BACKUP_TAG_LEN = 16;

function backup_encrypt(string $plain, string $appSecret): string {
    $key = ipam_hkdf_sha256($appSecret, 'ipam-v3:backup', 32);
    $iv  = random_bytes(BACKUP_IV_LEN);
    $tag = '';
    $ct  = openssl_encrypt($plain, 'aes-256-gcm', $key, OPENSSL_RAW_DATA, $iv, $tag, '', BACKUP_TAG_LEN);
    if ($ct === false) {
        throw new RuntimeException('backup encryption failed');
    }
    return BACKUP_MAGIC . $iv . $tag . $ct;
}

function backup_decrypt(string $blob, string $appSecret): string {
    if (strlen($blob) < strlen(BACKUP_MAGIC) + BACKUP_IV_LEN + BACKUP_TAG_LEN) {
        throw new RuntimeException('encrypted blob too short');
    }
    if (substr($blob, 0, strlen(BACKUP_MAGIC)) !== BACKUP_MAGIC) {
        throw new RuntimeException('not an IPAM backup blob (bad magic)');
    }
    $offset = strlen(BACKUP_MAGIC);
    $iv  = substr($blob, $offset, BACKUP_IV_LEN);
    $tag = substr($blob, $offset + BACKUP_IV_LEN, BACKUP_TAG_LEN);
    $ct  = substr($blob, $offset + BACKUP_IV_LEN + BACKUP_TAG_LEN);
    $key = ipam_hkdf_sha256($appSecret, 'ipam-v3:backup', 32);
    $pt  = openssl_decrypt($ct, 'aes-256-gcm', $key, OPENSSL_RAW_DATA, $iv, $tag);
    if ($pt === false) {
        throw new RuntimeException('backup decryption failed (auth or key)');
    }
    return $pt;
}
```

### Task 3.2: Implement the algorithm

**Files:**
- Modify: `Simple-PHP-IPAM/lib.php`

- [ ] **Step 1: Implement `ipam_gfs_select_for_deletion()`**

Algorithm:
1. Sort `$backups` newest-first.
2. Walk in order, bucketing each by tier slot: hourly (`Y-m-d H`), daily (`Y-m-d`), weekly (ISO week), monthly (`Y-m`).
3. The **first** backup in each unique slot that has remaining capacity in that tier "wins" the slot for that tier.
4. A backup is **kept** if it wins at least one slot in any tier.
5. Newest backup is always kept regardless of counts (safety).
6. All others go in delete list.

**Files:**

- [ ] **Step 1: Compose dump → encrypt → upload → log → retain**

Pseudocode:

```php
class BackupEngine {
    public function __construct(private PDO $db, private array $config) {}

    public function runForDestination(int $destId, string $triggeredBy = 'manual'): array
    {
        $dest = $this->loadDestination($destId);
        $client = $this->clientFor($dest);

        // 1. Dump DB to tmp file (use existing backup.php logic — refactor it into a shared helper)
        $tmpSql = ipam_dump_database_to_tmp();        // gzipped .sql.gz

        // 2. Encrypt if dest.encrypt
        if ($dest['encrypt']) {
            $tmpFile = ipam_encrypt_file_to_tmp($tmpSql, $this->config['app_secret']);
            $extension = '.enc';
        } else {
            $tmpFile = $tmpSql;
            $extension = '.sql.gz';
        }

        // 3. Upload
        $remoteName = sprintf('ipam-backup-%s%s', date('Ymd-His'), $extension);
        $logId = $this->insertLog($destId, $triggeredBy, 'running', $remoteName);
        try {
            $meta = $client->upload($tmpFile, $remoteName);
            $this->updateLogSuccess($logId, $meta);
        } catch (Throwable $e) {
            $this->updateLogFailure($logId, $e->getMessage());
            audit($this->db, 'backup.failed', 'destination', $destId, $e->getMessage());
            $this->maybeNotify($dest, 'failure', $e->getMessage());
            throw $e;
        } finally {
            @unlink($tmpFile);
            if ($tmpSql !== $tmpFile) @unlink($tmpSql);
        }

        // 4. Retain
        $deleted = ipam_backup_apply_retention($this->db, $destId);

        audit($this->db, 'backup.run', 'destination', $destId,
              "remote={$remoteName} size={$meta['size']} pruned={$deleted}");
        $this->maybeNotify($dest, 'success', $remoteName);

        return ['log_id' => $logId, 'filename' => $remoteName, 'size' => $meta['size']];
    }
}
```
