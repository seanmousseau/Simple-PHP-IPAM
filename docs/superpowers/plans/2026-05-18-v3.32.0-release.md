# v3.32.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Simple-PHP-IPAM v3.32.0 — a code-quality, hardening, and dependency-maintenance release closing the 9 issues in GitHub milestone #84.

**Architecture:** No schema migrations. Work lands on `dev` as discrete fixes (one commit per issue), then the standard 4-phase release workflow (`docs/internal/release-workflow.md`): prep + bundle on `dev`, PR `dev → main`, CodeRabbit/CI review, merge + tag + deploy + marketing site.

**Tech Stack:** PHP 8.2+, SQLite/MySQL/PostgreSQL (3-driver), PHPUnit, PHPStan L9, PHP_CodeSniffer, Playwright, semgrep, Composer.

**Scope decisions (locked with maintainer):**
- #1200 / #1199 deps: **evaluate, upgrade if low-risk.** Read changelogs; take the bump only if breaking changes are minor/absent, else document findings on the issue and defer the bump (issue stays open, milestone moved).
- #1206 VR baselines: **included** in v3.32.0.

**Non-negotiables:** No `git push`, PR create, or merge without explicit per-action approval. Full local 3-driver gate green before any push. All local test failures fixed, never dismissed as flake. Memory MCP updated as work happens (one observation per change with `git rev-parse --short HEAD`).

function ipam_prefix_to_netmask(int $prefix): string

- [ ] **Step 3: Add the helper to `lib/db.php`**

```php
/**
 * Fetch one associative row; returns [] on null statement or false fetch
 * (driver disconnect / exhausted result). Callers index the result safely.
 */
function ipam_fetch_assoc(?PDOStatement $st): array
{
    if ($st === null) return [];
    $row = $st->fetch(PDO::FETCH_ASSOC);
    return is_array($row) ? $row : [];
}
```
