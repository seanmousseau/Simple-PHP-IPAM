- [ ] **Step 1.1: Write the enumeration tool**

`tools/audit-at-suppressions.php` walks `Simple-PHP-IPAM/` and emits a TSV of `file<TAB>line<TAB>callsite<TAB>has_adjacent_comment` for every `@`-prefixed I/O call.

```php
<?php
declare(strict_types=1);
// Usage: php tools/audit-at-suppressions.php
$root = dirname(__DIR__);
$targets = ['file_get_contents','file_put_contents','chmod','mkdir','unlink','fopen','fread','fwrite','fclose','flock','rename','copy','touch','is_readable','is_writable','date_default_timezone_set'];
$pattern = '/@(' . implode('|', array_map('preg_quote', $targets)) . ')\s*\(/';
$rii = new RecursiveIteratorIterator(new RecursiveDirectoryIterator($root, FilesystemIterator::SKIP_DOTS));
foreach ($rii as $f) {
    if ($f->getExtension() !== 'php') continue;
    $path = $f->getPathname();
    if (str_contains($path, '/vendor/') || str_contains($path, '/node_modules/')) continue;
    $lines = file($path);
    foreach ($lines as $i => $line) {
        if (preg_match($pattern, $line, $m)) {
            $prev = trim($lines[$i - 1] ?? '');
            $sameLine = trim($line);
            $hasComment = str_contains($prev, '//') || str_contains($sameLine, '//') || str_starts_with($prev, '*');
            echo str_replace($root . '/', '', $path) . "\t" . ($i + 1) . "\t" . trim($line) . "\t" . ($hasComment ? 'Y' : 'N') . "\n";
        }
    }
}
```

## Task 2: #946 — TOTP backup-code O(N) `password_verify` scan

**Scope:** `Simple-PHP-IPAM/lib.php:6871-6887` (`ipam_totp_verify_backup_code`) currently iterates every unused backup-code row and calls `password_verify` per row. Add a non-secret discriminator (lookup key) so verification candidates are pre-filtered.

- [ ] **Step 2.1: Pick the lookup-key scheme**

Use a **HMAC-SHA256 truncated to 4 bytes (8 hex)**, keyed with `app_secret`. Non-secret on its own; reversible-resistance via the keyed HMAC; 4-byte truncation keeps it a narrow discriminator (≈1-in-4-billion collision) so a verifier only password_verifies ≤1 row in practice. Bcrypt's salt still owns the security guarantee — the lookup_key is purely an index optimisation.

function ipam_totp_verify_backup_code(PDO $db, int $userId, string $code): bool {
    $lk = ipam_totp_backup_lookup_key($code);
    // Narrow candidates by lookup_key; legacy rows with NULL lookup_key fall back to the slow path for one release.
    $stmt = $db->prepare(
        "SELECT id, code_hash FROM totp_backup_codes
         WHERE user_id = :uid AND used_at IS NULL AND (lookup_key = :lk OR lookup_key IS NULL)"
    );
    $stmt->execute([':uid' => $userId, ':lk' => $lk]);
    $nowExpr = ipam_dialect()->now();
    foreach ($stmt->fetchAll(PDO::FETCH_ASSOC) as $row) {
        if (password_verify($code, (string)$row['code_hash'])) {
            $consume = $db->prepare(
                "UPDATE totp_backup_codes SET used_at = {$nowExpr} WHERE id = :id AND used_at IS NULL"
            );
            $consume->execute([':id' => $row['id']]);
            return $consume->rowCount() === 1;
        }
    }
    return false;
}
