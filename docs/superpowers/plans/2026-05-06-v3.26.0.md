### Task C8: #876 — client_ip() XFF RTL walk (A10)

**Files:**
- Modify: `Simple-PHP-IPAM/lib.php:1084-1095`
- Modify: settings registry (add `proxy_trust_cidrs` setting)

- [ ] **Step 1: Add `proxy_trust_cidrs` setting (multi-line CIDR list)**

Default: empty list. Sensitive: false.

- [ ] **Step 2: Implement RTL walk**

```php
function client_ip(): string {
    $remote = $_SERVER['REMOTE_ADDR'] ?? '0.0.0.0';
    $trustedCidrs = ipam_setting('proxy_trust_cidrs', '');
    if (!$trustedCidrs) return $remote;
    $cidrs = array_filter(array_map('trim', explode("\n", $trustedCidrs)));
    if (empty($cidrs)) return $remote;
    if (!ip_in_any_cidr($remote, $cidrs)) return $remote;  // direct connection from untrusted source

    $xff = $_SERVER['HTTP_X_FORWARDED_FOR'] ?? '';
    $hops = array_reverse(array_map('trim', explode(',', $xff)));
    $candidate = $remote;
    foreach ($hops as $hop) {
        if (ip_in_any_cidr($hop, $cidrs)) {
            $candidate = $hop;
            continue;
        }
        return $hop;  // first untrusted = real client
    }
    return $candidate;
}
```

Add `ip_in_any_cidr(string $ip, array $cidrs): bool` helper.

- direct from trusted, no XFF → returns REMOTE_ADDR
- one trusted hop → returns first untrusted from RTL
- multi-hop chain (3 trusted, then client) → returns client
- spoofed leftmost ignored
