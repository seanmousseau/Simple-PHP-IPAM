# v3.20.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to execute task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Each task MUST run the per-task local gate before commit. Each task references the issue body for full acceptance criteria — do not duplicate here.

**Goal:** Ship v3.20.0 — the destinations-UX overhaul + deferred CR fixups (13 issues from milestone #47), aligned with `docs/internal/backup_overhaul.md` §C.

**Architecture:** No new architecture. v3.20.0 fills CRUD gaps on the existing `destinations.php` page, wires already-built helpers (`ipam_backup_notify`, `ipam_format_datetime`), tightens redaction, and adds the long-missing MinIO-backed integration test. The unified `Backup & Restore` surface lands in v3.21.0 — explicitly out of scope here.

**Tech Stack:** PHP 8.2 + SQLite/MySQL/PostgreSQL via PDO; vanilla CSS/JS; Composer-managed runtime deps; Playwright + PHPUnit + PHPStan + PHPCS + semgrep; MinIO (sidecar) for #789.

**Project conventions in force:** see `CLAUDE.md` and procedure docs. Non-negotiable: no PR/merge without explicit per-action user approval; full local 3-driver dockerized gate before push; no shortcuts.
