**Companion to:** `2026-05-08-v3.27.1-hotfix.md`
**Test target:** SQLite test instance at `https://dev-direct.seanmousseau.com:8343/testing/ipam/` (container `dev_seanmousseau_com-apache-php-1` on `192.168.80.15`).
**Driver:** Playwright MCP (`mcp__plugin_playwright_playwright__*`) from this Claude session.
**Operator:** Claude (foreground), with Sean reviewing transcripts and screenshots.

> **Why a manual regression sweep before code:** the architecture writeup found one shipped-but-incomplete feature ("vault relocation reads-only") that hid behind a fallback path for two minor releases. We don't know yet whether other v3.21 → v3.27 features have similar half-finished shapes. A two-pass manual sweep against a real instance — once on current v3.27.0 to capture today's behaviour, once on v3.27.1 to confirm the fix and detect collateral — gives us evidence we don't have from unit tests alone.

## 15. Stop conditions / gotchas

- **Stop and surface:** any 500 error, any unexpected redirect, any sudo grant that outlives a stated invalidation trigger (logout, role change, MFA enroll change), any `backup.preflight_failed` audit row missing during a known-broken Pass-A run, any test step where Pass A's actual behaviour differs from "the architecture doc's predicted bug." The architecture doc's predictions are themselves under test.
- **Test admin lockout safety:** before §2.4–2.6, confirm the test instance has at least two active admins or an OIDC fallback. The self-protection guards prevent us from disabling our own only path back in.
- **Rate-limit reset:** §2.92 burns the 5/15min sudo bucket. Allow 15 min wall clock or manually reset `auth_failures` table before any subsequent step-up tests in the same pass.
- **Don't push to remote storage:** keep all backup destinations in §3 as Local. The bug we're testing is destination-agnostic; we don't need to touch S3/SFTP from the test instance, and we shouldn't pollute prod buckets with test fixtures.
- **Don't run §11 Demo mode tests on a non-demo instance:** the prod-like SQLite test instance is NOT demo mode; demo_reset would wipe all the RT-20260508 fixtures partway through.
