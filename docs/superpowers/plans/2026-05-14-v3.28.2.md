```bash
  [ "$1" = "--" ] && shift
  if /usr/bin/time -l true >/dev/null 2>&1; then
```

```php
<?php
declare(strict_types=1);

/**
 * Return the configured `app_secret`. Auto-generate + persist into config.php
 * on first need (mirrors ipam_bootstrap_key()). Fail loudly when config.php
 * is read-only; never regenerate on every cold request.
 *
 * Side effects on auto-gen path:
 *   - audit('app_secret_autogenerated', 'system', null, ...)
 *   - settings row install_keys_announce.app_secret = 1 (one-shot banner)
 *
 * @param string|null $configPathOverride  Test-seam; production callers omit this.
 */
function ipam_app_secret(?string $configPathOverride = null): string
{
    static $cached = null;
    if (is_string($cached) && $cached !== '') {
        return $cached;
    }

    /** @var array<string,mixed> $config */
    global $config;

    $existing = isset($config['app_secret']) && is_string($config['app_secret'])
        ? $config['app_secret']
        : '';

    if ($existing !== '') {
        $cached = $existing;
        return $existing;
    }

    if (function_exists('ipam_assert_random_bytes_available')) {
        ipam_assert_random_bytes_available();
    }
    $new = base64_encode(random_bytes(32));

    $configPath = $configPathOverride ?? realpath(__DIR__ . '/../config.php');
    if ($configPath === false) {
        throw new RuntimeException(
            'app_secret auto-generation: config.php path does not resolve. '
            . 'Set app_secret manually in config.php and retry.'
        );
    }

    if (!is_writable($configPath)) {
        throw new RuntimeException(
            'app_secret auto-generation: config.php is not writable. '
            . 'Set app_secret manually in config.php (e.g. '
            . '`php -r "echo base64_encode(random_bytes(32));"`) and retry.'
        );
    }

    try {
        ipam_config_inject_or_replace_key($configPath, 'app_secret', $new);
    } catch (Throwable $e) {
        throw new RuntimeException(
            'app_secret auto-generation could not update config.php: ' . $e->getMessage()
            . '. Set app_secret manually and retry.',
            0,
            $e
        );
    }

    // Concurrency guard: re-read post-rename so racers converge.
    /** @var array<string,mixed>|false $persisted */
    $persisted = @include $configPath;
    if (is_array($persisted) && isset($persisted['app_secret']) && is_string($persisted['app_secret'])
        && $persisted['app_secret'] !== '') {
        $new = $persisted['app_secret'];
    }

    $config['app_secret'] = $new;
    $cached = $new;

    if (function_exists('ipam_install_key_announce_record')) {
        ipam_install_key_announce_record('app_secret');
    }
    return $new;
}
```

```php
function ipam_install_key_announce_record(string $key): void
{
    if (!in_array($key, ['app_secret', 'bootstrap_key'], true)) {
        return;
    }
    if (!function_exists('db_connect')) {
        return;
    }
    try {
        $db = db_connect();
        audit($db, $key . '_autogenerated', 'install_key', null,
              'Auto-generated on first use; review docs/internal/runbooks.md');
        $stmt = $db->prepare(
            "INSERT INTO settings(name, value) VALUES(:k, '1') "
            . "ON CONFLICT(name) DO UPDATE SET value='1'"
        );
        $stmt->execute([':k' => 'install_keys_announce.' . $key]);
    } catch (Throwable $e) {
        // Auto-gen must not fail the request just because audit logging fell over.
        error_log('install_key_announce_record failed: ' . $e->getMessage());
    }
}
```

## Risks / red flags to watch for

- **`app_secret` rotation:** lazy auto-gen ties config.php to TOTP enrollments forever. The banner + docs must make this clear or operators will lose 2FA on the first `config.php` mishap. Banner copy is non-optional.
- **MySQL upsert parity:** the announce-flag write uses engine-specific `ON CONFLICT` vs `ON DUPLICATE KEY` — easy to miss one driver. Run the 3-driver pass.
- **`config.php` writability on hardened installs:** some operators chmod `config.php` 0o400 after deploy. The new RuntimeException must be actionable, not silent.
- **Marketing site cache layers:** OPcache + LSCache + Cloudflare. Skipping any one leaves stale version on the homepage.
- **Bundle/code drift in Phase 3:** the easy mistake is fixing CR comments inside `Simple-PHP-IPAM/` and forgetting to rebuild. The `git diff --stat releases/...` check in Task 24 catches it; run it every round.
