### Task 4: `#1104` vendor/lock drift detection

- [ ] **Step 1: Write the drift-check script**

```bash
#!/usr/bin/env bash
# v3.29.0 #1104 — Fails if vendor/ disagrees with composer.lock.
# Detects the "PHPStan/PHPUnit version mismatch trap" where a developer
# pulls main and forgets `composer install`; the gate then runs against
# a stale vendor/ and produces confusing per-test failures that look
# like real regressions.
set -euo pipefail

if ! command -v composer >/dev/null 2>&1; then
  echo "composer not on PATH" >&2
  exit 1
fi

if ! composer validate --no-check-publish --strict >/dev/null 2>&1; then
  echo "composer validate failed: composer.json / composer.lock invalid" >&2
  exit 1
fi

if [ -d vendor ]; then
  # `composer status` exits non-zero if installed pins drift from the lock.
  if ! composer status --no-interaction >/dev/null 2>&1; then
    echo "vendor/ drifts from composer.lock. Run: composer install" >&2
    exit 1
  fi
fi
```

Save as `testing/scripts/check-composer-lock-drift.sh`. Make executable: `chmod +x testing/scripts/check-composer-lock-drift.sh`.

### Task 5: `#1106` phpunit-against-driver helper script

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# v3.29.0 #1106 — Run PHPUnit against a running ipam-pw-{mysql,pgsql}
# container without needing to remember docker exec incantations or
# DSN env vars.
#
# Usage:
#   testing/scripts/phpunit-against-driver.sh mysql
#   testing/scripts/phpunit-against-driver.sh pgsql
#   testing/scripts/phpunit-against-driver.sh mysql tests/Mysql/MysqlSmokeTest.php
set -euo pipefail

driver="${1:-}"; shift || true
case "$driver" in
  mysql)  container=ipam-pw-mysql;  dsn='mysql:host=127.0.0.1;port=3306;dbname=ipam_pw';;
  pgsql)  container=ipam-pw-pgsql;  dsn='pgsql:host=127.0.0.1;port=5432;dbname=ipam_pw';;
  *) echo "usage: $0 {mysql|pgsql} [phpunit args...]" >&2; exit 2;;
esac

if ! docker ps --format '{{.Names}}' | grep -q "^${container}$"; then
  echo "container $container not running. Run: bash testing/playwright/bootstrap-app.sh $driver" >&2
  exit 1
fi

IPAM_TEST_DSN="$dsn" IPAM_TEST_USER=ipam IPAM_TEST_PASS=ipam_password \
  vendor/bin/phpunit "$@"
```

### Task 12: `#903` InMemoryDb test helper

Helper contract:

```php
namespace Tests\Helpers;

final class InMemoryDb
{
    /**
     * Open a fresh SQLite in-memory PDO with the schema from
     * schema.sql applied. For MySQL/Postgres tests, prefer the
     * docker-bootstrapped containers via phpunit-against-driver.sh
     * (#1106) — in-memory is sqlite-only by definition.
     */
    public static function fresh(): \PDO
    {
        $pdo = new \PDO('sqlite::memory:');
        $pdo->setAttribute(\PDO::ATTR_ERRMODE, \PDO::ERRMODE_EXCEPTION);
        $schema = file_get_contents(__DIR__ . '/../../Simple-PHP-IPAM/schema.sql');
        if ($schema === false) {
            throw new \RuntimeException('schema.sql missing');
        }
        foreach (explode(';', $schema) as $stmt) {
            $stmt = trim($stmt);
            if ($stmt !== '') {
                $pdo->prepare($stmt . ';')->execute();
            }
        }
        return $pdo;
    }

    /**
     * Same as fresh() but also runs apply_migrations() so the DB
     * matches what an upgrade-path install would see.
     */
    public static function withMigrations(): \PDO
    {
        $pdo = self::fresh();
        require_once __DIR__ . '/../../Simple-PHP-IPAM/lib.php';
        require_once __DIR__ . '/../../Simple-PHP-IPAM/migrations.php';
        apply_migrations($pdo);
        return $pdo;
    }
}
```
