**Goal:** Ship v3.18.0 — a polish release closing 5 milestone issues: settings.php per-toggle save refactor (#756), v3.16.0 UX/CSS polish bundle (#758), contacts UI documentation (#759), pgsql Playwright flake fix (#760), and 5 deferred CR backup/restore items (#762, items 2–6).
